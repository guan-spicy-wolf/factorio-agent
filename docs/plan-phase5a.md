# 阶段 5a 实验：流体机器——塑料，再做硫酸

接续 `docs/plan-phase4b.md`。实验规则沿用 `docs/plan-phase6a.md`（不给排法、自行迭代、全程记录到 `docs/experiments/5a-fluids.md`）。4b 的结论是"周期求解不再有搜索这个工作项，只剩给求解器加结构词汇"。本轮用第一类流体结构检验这句话：**加一类结构要多少行、落在哪几个文件、agent 能否自己加成。**

## 1. 范围

- **主任务：塑料**（plastic-bar：石油气 + 煤 → 塑料棒）。一个液体输入、一个固体输入、固体输出上带。化工厂 3×3，液体口位置随朝向变、支持 `mirror`；配方无液体输出，但输出侧液体口照样存在。
- **次任务：硫酸**（sulfuric-acid：硫 + 铁板 + 水 → 硫酸）。液体输入加液体输出，补"液体口作为单元输出"的契约。
- 上游罐区与炼油厂是固定/锚定单元，本轮不做；液体输入由 `infinity-pipe` 夹具代替，液体输出由储罐或 infinity-pipe 汇接收。
- 不做炼油厂、裂化、信标、模块；不改已有家族排法。

## 2. 必须由执行者自己做并记录的事

1. **几何库**：液体口随朝向与镜像的变换（`geom/fluid.py` 目前只做了 N 向连接点）。实机核对化工厂四个朝向加镜像的口位置、`mirror` 字段在蓝图导入后的实际效果、输入口与输出口的区分。写进 VERIFY.md 新节。
2. **2.1 流体模型**：段内流量是否受管长影响（2.0 起据称段内不受长度限制，有段长上限）；地下管、储罐对段的影响。实机确认后决定契约里液体速率要不要带距离假设。
3. **求解器结构词汇**（CP-SAT 后端）：管道母线（沿带方向的管行）、机器朝向与镜像变量、液体口对接到母线、`fluid.unintended_adjacency` 在周期内与跨周期的表达、输出侧闲置液体口不得与母线相邻。穷尽搜索后端不要求支持流体，但要能明确拒绝并提示用 CP-SAT。
4. **契约**：液体口加流量与温度；`requires` 里液体的 `MinRate`；输出液体口（硫酸）作为 `Interface`。
5. **夹具与路由**：infinity-pipe 源经阶段 3a 的管道路由接到单元液体口；硫酸输出接储罐汇并读量。
6. **生成器**：塑料与硫酸走 `direct_chain` 家族（或新家族，由执行者判断并说明理由），目标产率塑料 1、2、4 棒/秒，硫酸 1、2 单位/秒（按配方产物计）。
7. **代码统计**：按"几何库 / 求解器约束 / 求解器驱动 / 契约 / 夹具与路由 / 生成器"分类统计新增非空非注释行数，与 4b 的红瓶、绿瓶对照。

## 3. 验收

| 项 | 判据 |
| --- | --- |
| 塑料 | 3 档产率通过 `validate`（含 `fluid.unintended_adjacency`）并实测达标；换化工厂镜像、换电杆、换爪子只改参数 |
| 硫酸 | 至少 1 档达标，液体输出口的实测流量与契约一致；做不到就记清卡在哪 |
| 对拍 | 塑料周期至少一种变体给出可证的最小面积；若 60 s 内证不出，返回可行解并标注未证 |
| 核对 | VERIFY.md 新节：化工厂口位置 × 朝向 × 镜像、`mirror` 语义、2.1 段内流量与管长、infinity-pipe 作为汇的行为 |
| 记录 | 最后一节回答："加一类结构要多少行、落在哪几层？哪些是 agent 一次写对的，哪些靠实机才发现？流体结构有没有逼出求解器之外的改动？" |

## 4. 约束

- 不放宽不变量；数字只在种子（化工厂、infinity-pipe 等缺的原型按 `ADD` 表补）；不写 if 实体名。
- `uv run pytest -m "not headless"` 不起服务器；OR-Tools 未装时流体相关求解测试 skip。
- 实测前全科技解锁，记录随附 `RuntimeState`。
