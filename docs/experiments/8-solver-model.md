### S1：静态带行分析（00:33–00:45）

`_Ctx.belt_rows(h, skeleton)`（按 (高度, 骨架) 缓存）+ `_solve_height(prune=True)`：不允许的 `row[b, y]` 固定为 0，不允许的锚点行不建 `P`，

IN（每台机器每条需要的带都要满速供料）与终产物 OUT；道投放与 LINK 不进分析——多台机器的阶段里某一台可以不投放、不供料，写进去就不精确了。

单模型（负载 3.8–4.2）：绿瓶 32×8 首解 8914 → **5252 变量、7.27 → 4.66 确定性 s、4.2 s 墙钟**；h=7 三个骨架**静态不可行**（0 s，不建模型）。

**范围（兼容性的取舍）**：S 精确，但只要改了模型，CP-SAT 给出的解就可能换一个；随时可用驱动的每一步又都与预算耦合（模型变快 → 剩余预算变 → 下一个模型的上限变）。
所以"所有模型都剪"会让调色板表里 3:2、红瓶、塑料、硫酸的随时可用行（它们第 0 级调色板的宽松尺寸没有地下带）换解，违反"`palette.jsonl` 的随时可用行不变"。
最终范围：

- 证明驱动：筛与固定宽度首解（只用状态）用 S；带目标的终解模型保持 4b 写法（K、S 都关），所以证明行的放置逐字不变；

  特征化表里只有绿瓶走到这一步（3:2、红瓶在宽松尺寸或子周期平铺拿到首解，流体跳过第 1 阶段）；
