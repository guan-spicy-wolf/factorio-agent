# 阶段 4a 实验：周期求解器与 3:2 绿板直插链

这是一次实验，规则沿用 `docs/plan-phase6a.md`：**只给目标、约束、工具和验收，不给排法**，执行者自己设计、自己迭代、全程记录到 `docs/experiments/4a-cycle-solver.md`。与 6a 的区别：这次没有公认的经典排法可以检索，是对"检索加验证"与"真正求解"的区分，也是 `docs/design.md` 标为最大风险的一项（"如果约束写起来比手写模板还难，应退回写死经典排法"）。实验要正面回答这个问题。

## 1. 目标

1. 一个**周期内求解器**：给定周期的配比（如 3 台铜线机 + 2 台绿板机）、机器与爪子等级、带和电杆等级，在一个小矩形区域里精确搜索机器、爪子、电杆的位置与朝向，使单个周期合法，且**平铺 n 次后**仍合法（周期边界条件）。
2. 一个新的生成器家族 `direct_chain`（配比周期的直插链），以求解器得到的周期为叶子，平铺成单元，输出接口契约，接入现有的 validate、渲染、夹具、实测。
3. 用 3:2 绿板链做第一个实例，并和一个手写的经典 3:2 排法对比吞吐与面积。

## 2. 约束

- 核心库仍零第三方运行时依赖：先用穷尽搜索加剪枝，不引入 OR-Tools。如果搜索在合理时间内（单个周期 ≤ 60 秒，4 核）跑不出来，记录证据后再决定是否把 CP-SAT 作为**可选**依赖，并说明理由。这一决定本身就是实验结论的一部分。
- 所有几何事实只从几何库取；约束必须复用现有不变量（`validate`）作为最终裁判，求解器内部可以有自己的增量检查，但不能与 `validate` 矛盾。
- 不写死任何数字或 if 实体名。配比、机器数、周期数由配方和目标产率算出（`gen/throughput.py`）。
- 2.1 的事实以实机为准。直插相关的两条先在仿真里试再写进 VERIFY.md：爪子直接从组装机取放是否需要隔一格（取放向量本身决定）、组装机输出被取空的节奏是否限制吞吐。
- 不改冶炼列与采矿生成器；不做信标、模块、多层周期。

## 3. 周期与边界条件的定义（必须由执行者写清并进代码）

- 周期是一个矩形区域 `W × H` 内的一组放置。平铺是沿一个轴以步长 `W`（或 `H`）复制 n 次。
- 边界条件：平铺后的合并布局必须通过全部不变量，包括带子连续（周期两端的带格要对齐并同向）、电杆跨周期连通、不出现新的爪子取放空格或重叠。
- 周期的接口：输入带（铁板、铜板）和输出带（绿板）在周期边缘的位置、方向、带道；中间产物（铜线）只在周期内部直插，不上带。配比不整齐时允许"略过剩"的近似整数比（见 `design.md`），要在契约 `assumptions` 里写明。
- 求解器输出要可解释：给出每个周期候选的面积、机器数、搜索时间、被哪条约束剪掉了多少分支。

## 4. 验收

| 项 | 判据 |
| --- | --- |
| 求解器 | 对 3:2 绿板周期（1 型或 2 型组装机、普通或快速爪、黄带、小杆或中杆）在 ≤ 60 秒内给出至少一个合法周期；平铺 4 次和 8 次后 `validate` 零违例 |
| 生成器 | `fgen gen direct-chain --recipe electronic-circuit --rate R` 对 R = 1、2、4 绿板/秒产出通过 validate 的单元，接口契约填全阶段 6a 的字段；`Infeasible` 有用例（如目标超过单带容量） |
| 实测 | 夹具供铁板与铜板，实测绿板产率 ≥ 目标；写 `characterization/direct_chain.{jsonl,md}` |
| 对比 | 手写一种经典 3:2 排法（执行者自己写，作为基线），表格对比求解器周期与手写周期的面积、机器数、实测吞吐 |
| 新约束成本 | 换爪子等级或电杆等级只改参数；记录新增一类约束（如"管道不意外相邻"这种本阶段不需要的）需要改哪几个文件，不改任何提示或任务书 |
| 记录 | `docs/experiments/4a-cycle-solver.md`：迭代、搜索规模与剪枝效果、失败、耗时统计；最后一节直接回答"约束编码比手写模板难吗，CP-SAT 该不该引入" |

## 5. 顺序建议（非强制）

先实机确认直插的两条事实，再写周期定义与边界条件的测试（用一个人为构造的可行周期验证平铺检查），然后写搜索，最后接生成器与实测。基线排法什么时候写由执行者定，但对比表必须有。
